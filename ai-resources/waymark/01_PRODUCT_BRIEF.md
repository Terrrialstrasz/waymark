# Waymark Product Brief

## Product identity

**Waymark** is a private, phone-first Life OS for walking chosen life paths, leaving proof that each day counted, preserving memories, reducing forgetfulness, and closing the day with purpose.

Tagline:

> Mark the path. Finish the day.

Core sentence:

> Codex writes the Map. I leave the Mark.

## Core metaphor

| Term | Meaning |
|---|---|
| Path | A meaningful life direction |
| Mark | Proof that a path was walked |
| Journal / Trail | Timeline of marks, memories, closures, and proof |
| Map | The coded life system, not a user-facing tab |
| Pack Check | Transition guard for attention and forgetfulness |
| Expedition | Long-horizon container that generates PlannedMarks |
| Weekly Coding | Weekly report/review/generation process |
| Close the Trail | End-of-day closure and Character judgment |

## Problems Waymark solves

| Problem | Waymark response |
|---|---|
| Forgetfulness during transitions | Pack Checks |
| Project overconsumption | Expeditions and Close Trail consumption detection |
| Days feeling unfinished | DailyClosure / Close the Trail |
| Phone distraction | Tools Gateway later |
| Life becoming only work | Path balance and required daily slots |
| Family becoming leftover time | Family marks, memories, and protected planned actions |
| Proof disappearing into photos | Memory archive and Journal |

## Emotional outcome

At the end of a day, the user should feel:

> Today counted. I did something right for the life I am building.

## Product boundaries

Waymark is not:

| Not this | Why |
|---|---|
| Generic task manager | It is centered on proof and life paths, not task volume |
| Habit streak app | Streak pressure is the wrong emotional tone |
| Productivity dashboard | It must serve a whole life, not maximize output |
| CMS/back office | The Map is code |
| Social app | Sharing is later and selected only |
| App blocker | The goal is intentional use, not restriction |
| AI-first app | AI is not a runtime dependency for core features |
| Fitness app clone | Health needs only the user’s simple A/Walk/B engine |

## Current user-facing navigation

| Tab | Purpose |
|---|---|
| Today | Operating cockpit |
| Capture | Fast input |
| Journal | Proof timeline and memories |
| Paths | Seven paths and path-owned expeditions |
| Me | Weekly report, Backlog, settings, privacy, language, backup |

There is **no top-level Map tab**.

## Main promise

> Waymark helps me walk my chosen paths, leave proof that today counted, and return to my life with attention.
