# Seven Life Paths

Waymark has seven fixed Life Paths.

Attention / Presence is not an eighth path. It is a cross-cutting layer through Pack Checks, Tools Gateway, and transition awareness.

## Path table

| Path ID | Path | Purpose | Daily question |
|---|---|---|---|
| `career_craft` | Career Craft | Become a top banking BA / leader / systems thinker | Did I deliver clarity or raise my standard today? |
| `snag_golf_vietnam` | SNAG Golf Vietnam | Build SNAG into a real institution-led junior golf education business | Did I build the institution today? |
| `health_body` | Health & Body | Protect energy, blood pressure, strength, and long-term capacity | Did I protect my body today? |
| `family_home` | Family & Home | Be a present husband and father | Did I give presence to my family today? |
| `character_stoicism` | Character & Stoicism | Build discipline, courage, restraint, responsibility, emotional control | Did I act according to my standard today? |
| `golf_craft` | Golf Craft | Improve golf skill and keep golf as lifelong craft | Did I practice or learn the craft today? |
| `culture_class_romance` | Culture, Class & Romance | Become refined, romantic, well-read, tasteful, intentional | Did I refine the man today? |

## Career Craft

Career is a planned work path, not a routine path.

| Rule | Meaning |
|---|---|
| Main flow | PlannedMark |
| Major work | Expedition(kind="project") |
| Valid proof | Finished artifact, clarified rule, resolved issue, prepared options, mentored, led alignment |
| Invalid proof | “Went to work,” “was busy,” “worked long hours” |
| UI | Career path screen owns Career Expeditions |

## SNAG Golf Vietnam

SNAG is separate from Career.

| Rule | Meaning |
|---|---|
| Main flow | PlannedMark |
| Content calendar | Expedition(kind="content_calendar") |
| Valid proof | Website, content, relationship, operation, institution, curriculum, league, proposal |
| UI | SNAG path screen owns SNAG Expeditions |

## Health & Body

Health has the main true outlier engine.

| Rule | Meaning |
|---|---|
| Cycle | Workout A → Walk → Workout B → repeat |
| Workout A/B | Exercises + stretch |
| Walk day | Walk only |
| Mark creation | Health Mark is created at session completion |
| Progression | Per exercise after X consecutive completions |
| Partial | Does not advance base cycle |

## Family & Home

Family protects wife, child, home, and memories from becoming leftovers.

| Rule | Meaning |
|---|---|
| Routine presence | QuickMarks |
| Family plan | PlannedMark proof that planning happened |
| Family trip | Expedition(kind="family_trip") |
| Family memory | Memory + Mark |
| Sensitive content | `private_sensitive` where needed |

## Character & Stoicism

Character is a derived integrity layer.

| Rule | Meaning |
|---|---|
| Main proof | Completing planned life across all paths |
| Explicit marks | Quick pressure/repair marks only |
| Close Trail | Generates Character Mark |
| Daily judgment | DailyClosure + CharacterEvidence |
| Consumed logic | Belongs to Close the Trail |

## Golf Craft

Golf is planned learning now, not routine yet.

| Rule | Meaning |
|---|---|
| Beginner practice | PlannedMarks |
| Golf event | Expedition(kind="golf_event") |
| Golf season | Expedition(kind="golf_season") |
| No training rung | Avoid custom ladder entity |
| Future routine | Repeated practice can later become QuickMark |

## Culture, Class & Romance

Culture is maintenance and refinement.

| Rule | Meaning |
|---|---|
| Routine refinement | QuickMarks |
| Reading shelf | Expedition(kind="reading_shelf") |
| Style check | PackCheckRun |
| No Goodreads app | Keep it light |
| Romance | QuickMark or PlannedMark, linked to Family if relevant |
