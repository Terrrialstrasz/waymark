# Visual UX Direction

## Design goal

Waymark should feel like:

> A warm, private field journal and life cockpit — friendly, tactile, calm, and personal.

Not:

- Corporate dashboard
- Sterile productivity app
- Habit streak app
- Heavy stoic journal
- Childish playground UI
- Spreadsheet-like planner

## Visual personality

| Trait | Meaning |
|---|---|
| Warm | Feels human and private |
| Clear | User understands Today quickly |
| Tactile | Rounded cards, soft shadows |
| Alive | Enough density to feel useful |
| Calm | No shame or aggressive pressure |
| Family-friendly | Memories and family path feel soft |
| Purposeful | Each UI element has a job |

## Color foundation

Use SNAG-inspired but calmer palette.

| Token | Color | Use |
|---|---|---|
| blue | `#1172BA` | Career, clarity, info |
| green | `#03A550` | Primary action, completed, Health |
| yellow | `#F3B30F` | Family, warmth, attention |
| red | `#EB2428` | Serious warnings only |
| background | `#F7F7F5` | App background |
| surface | `#FFFFFF` | Cards |
| text | `#3E3E3E` | Primary text |

## Typography

Use soft, rounded, readable fonts with Vietnamese diacritic support.

| Element | Direction |
|---|---|
| Screen title | Large, bold, warm |
| Section title | Clear and readable |
| Card title | Strong but compact |
| Body text | Readable on phone |
| Metadata | Smaller but not tiny |
| Empty state | Human and calm |

## Component style

| Component | Direction |
|---|---|
| Cards | Rounded, soft shadow, breathable |
| Buttons | Large tap targets |
| Mark buttons | Tactile, immediate feedback |
| Pack Checks | Clear checklist rows |
| Journal items | Timeline-like but warm |
| Memory cards | Photo-forward |
| Warnings | Direct, not harsh |

## Motion

| Action | Feedback |
|---|---|
| Tap Mark | Gentle check animation |
| Complete Pack Check | Warm completion state |
| Close Trail | Quiet completion, no fireworks |
| Warning appears | Smooth card, not aggressive popup |
| Language switch | Immediate UI update if page ready |

## Density rule

Today should not feel empty. It should have 4–6 useful modules when flows are ready. But incomplete modules must stay hidden.

| Screen | Density target |
|---|---|
| Today | Alive and actionable |
| Capture | Simple and fast |
| Journal | Warm timeline |
| Paths | Seven cards/chips, scan-friendly |
| Me | Calm control room |
| Close Trail | Focused and complete |

## Accessibility

| Requirement | Meaning |
|---|---|
| High contrast text | Readable on tinted cards |
| Large touch targets | Mark buttons and checklist rows |
| Avoid color-only meaning | Use icons and labels |
| Vietnamese readable | No clipped diacritics |
| No tiny metadata | Phone-first readability |

## UX copy tone

Use:

- Marked.
- Today is marked. Rest.
- One mark can save the day.
- Pack check before you step out.
- What marks did you leave today?

Avoid:

- You failed.
- Streak lost.
- Crush your goals.
- Maximize productivity.
- You are behind.
