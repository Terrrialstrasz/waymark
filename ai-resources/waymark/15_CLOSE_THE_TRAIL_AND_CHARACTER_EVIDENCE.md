# Close the Trail and Character Evidence

## Core principle

Close the Trail is its own domain flow.

> It owns planned-vs-completed, consumed path, anchor path deviation, Character result, and tomorrow’s first step.

It is not just a Mark. It creates a `DailyClosure` and then generates an extra Character/Stoicism Mark.

## Entities

| Entity | Purpose |
|---|---|
| DailyClosure | End-of-day record and judgment |
| CharacterEvidence | Derived integrity evidence, stored as JSON |
| Mark | Extra Character Mark generated by closure |

## Close Trail reads

| Entity | Why |
|---|---|
| DailyPlan | Anchor path and required slots |
| PlannedMark | Planned vs completed |
| Mark | Actual proof |
| PackCheckRun | Attention/transition proof |
| WorkoutSessionRun | Body protection proof |
| Memory | Memory proof/archive |
| Expedition | Consumption/dominance context |
| Signal | Optional active reminders |

## Close Trail writes

| Output | Purpose |
|---|---|
| DailyClosure | Day judgment |
| CharacterEvidence JSON | Derived integrity data |
| Character Mark | Counts toward Character path balance |
| PlannedMark statuses | Missed/postponed/substituted summary |
| Tomorrow first step | Seeds next day |

## Day statuses

| Status | Meaning |
|---|---|
| finished | Enough right marks were left |
| partial | Real progress but important path missed |
| consumed | One path/project dominated too much |
| recovered | Light day but health/family/rest protected |
| reset_needed | Tomorrow should be simpler |

## Character results

| Result | Meaning |
|---|---|
| held | User upheld standard |
| protected | User protected essential paths |
| repaired | User corrected a lapse |
| faced_reality | User told the truth about the day |
| drifted | User lost the thread |
| consumed | One path/project took over |
| reset_needed | Simpler tomorrow required |

## Close Trail flow

```text
Open Close the Trail
  → show marks left today
  → show planned vs completed
  → detect consumed path
  → detect anchor deviation
  → suggest Character result
  → user confirms/adjusts
  → user enters tomorrow first step
  → save DailyClosure
  → create Character Mark
  → show “Today is marked. Rest.”
```

## Logic ownership

| Logic | Owner |
|---|---|
| Planned vs completed | DailyClosure |
| Consumed day | DailyClosure |
| Anchor path deviation | DailyClosure |
| Missed planned marks | DailyClosure |
| Character result | CharacterEvidence/DailyClosure |
| Mark proof | Mark only |

## Acceptance criteria

| Test | Expected |
|---|---|
| Open Close Trail | Today summary appears |
| PlannedMark completed | Counted as completed |
| PlannedMark not done | Can be missed/postponed/substituted |
| One path dominates | Consumed path suggested |
| Anchor differs from actual | Deviation recorded |
| Save closure | DailyClosure created |
| Closure saved | Character Mark generated |
| Reopen Today | Day shows closed state |
