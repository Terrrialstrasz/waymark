# FoundationColorSystem

Locked direction: `Eye Comfort Hybrid`

This foundation layer defines the Waymark palette used by primitives, domain components, and review boards.

Core rules:

- Use `foundationColors` and semantic tokens instead of raw hex values in components.
- Prefer cream paper surfaces over white.
- Use warm ink for readable body copy and metadata.
- Reserve deep green for primary/protected actions and states.
- Use gold as proof and intention accent, not as small standalone text.
- Use clay and missed tones as humane repair signals, not alarm colors.
- Keep archive blue contextual to memory and archive moments.
