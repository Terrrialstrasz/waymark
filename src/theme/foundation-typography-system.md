# FoundationTypographySystem

Direction: `Fresh Field Journal Serif`

Core rule:

- Serif creates Waymark's field-journal soul.
- Sans keeps Waymark usable, readable, and calm.

Runtime note:

- This repo currently uses runtime serif/sans fallbacks for native rendering.
- The intended pairings are defined in `foundation-typography.ts`.
- Custom Noto font loading can be layered in later using the project's approved font-loading path.

Primary files:

- `src/theme/foundation-typography.ts`
- `src/theme/tokens.ts`
- `src/labs/TypographyLab.tsx`
